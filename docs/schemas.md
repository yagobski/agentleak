# JSON Schema catalog

AgentLeak publishes versioned Draft 2020-12 JSON Schemas for its public file and
document formats. Use them to validate generated traces, configuration files,
reports and agent-produced requests before execution.

## Discover schemas

```bash
curl -sS https://agents.fomox.com/api/schemas | jq
agentleak schema
```

The catalog returns a schema version and the URL of every named contract. Fetch
one contract online or through the local CLI:

```bash
curl -sS https://agents.fomox.com/api/schemas/trace > trace.schema.json
agentleak schema analysis-report > report.schema.json
```

Unknown names return HTTP 404 or CLI exit code 1. Discover names from the
catalog rather than hardcoding an unverified URL.

## Available contracts

| Name | Validates |
| --- | --- |
| `config` | Complete `agentleak.yaml` configuration. |
| `trace` | Ordered normalized agent execution trace. |
| `event` | One channel-tagged trace event. |
| `finding` | One runtime privacy finding. |
| `analysis-report` | Complete scored report and privacy policy decision. |
| `privacy-policy` | Declarative privacy assertion configuration. |
| `privacy-policy-evaluation` | Assertion checks and violations. |
| `redteam-request` | Red-team campaign request body. |
| `code-scan` | Static source scan result. |
| `agent-card` | Agent identity, capabilities, source and privacy declaration. |

Every named document includes `x-agentleak-schema-version`. The schema version
tracks contract changes independently of the Python package version.

## IDE configuration

New files generated by `agentleak init` include:

```yaml
# yaml-language-server: $schema=https://agents.fomox.com/api/schemas/config
```

Editors supporting YAML Language Server can then autocomplete fields and reject
invalid values before a test starts.

## CI validation

Use the native validators first:

```bash
agentleak validate agentleak.yaml --trace traces/release.json
```

For language-independent pipelines, fetch and pin the schema version, validate
with any Draft 2020-12 implementation, then run AgentLeak. Schema validation
checks shape and types; it does not replace privacy detection or policy
evaluation.

## OpenAPI versus JSON Schema

`/openapi.json` is authoritative for HTTP paths, authentication, status codes
and API request/response envelopes. `/api/schemas` is authoritative for smaller
portable documents used both online and offline. Use both when generating an
API client that also reads CLI artifacts.

## Compatibility rules

- Consumers should ignore unknown optional properties.
- Producers must include required fields and valid enum values.
- Pin `x-agentleak-schema-version` when reproducibility matters.
- Validate before acting on agent-generated files or requests.
- Treat redacted findings and paths as sensitive operational metadata.
